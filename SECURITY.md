# Security policy

This is experimental kernel code. The latest development version is the only
version actively considered for fixes; no response-time guarantee is offered.

Report potential memory-safety, checksum-validation, or privilege-boundary
issues privately to Shun Li <riverscn@gmail.com>. If the repository enables
GitHub private vulnerability reporting, that channel is also appropriate.
Do not open a public issue containing a working exploit, credentials, packet
payloads or private system diagnostics before coordinated review.

Provide the affected package/kernel version, a minimal synthetic reproducer,
impact, and whether the issue also affects the upstream driver. Keep identifiers
and sensitive payloads redacted. Upstream issues should be coordinated with the
relevant kernel maintainers through their published process.

This repository does not collect telemetry or upload diagnostic bundles.
